<h1>🛒 Store Sales & Profit Analysis using Python</h1>

<p>
This project focuses on analyzing the sales and profit performance of a retail store using Python. 
By exploring historical sales data, this project provides actionable insights for strategic decision-making, 
optimizing inventory, improving marketing strategies, and maximizing profitability.
</p>

<hr>

<h2>📌 Project Objectives</h2>
<ul>
    <li>Analyze sales trends over time to identify peak and low-performing periods.</li>
    <li>Evaluate profit contributions by product, category, and customer segment.</li>
    <li>Utilize Python libraries for data preprocessing, visualization, and analysis.</li>
    <li>Generate actionable insights for inventory, marketing, and operational optimization.</li>
    <li>Develop an interactive and insightful data analysis workflow.</li>
</ul>

<hr>

<h2>📂 Dataset Description</h2>
<p>
The dataset includes key attributes such as:
</p>
<ul>
    <li><b>Order ID</b> – Unique identifier for each order</li>
    <li><b>Product Name</b> – Name of the product</li>
    <li><b>Category</b> – Product category</li>
    <li><b>Sub-Category</b> – Product sub-category</li>
    <li><b>Sales</b> – Revenue generated from each order</li>
    <li><b>Profit</b> – Profit earned from each order</li>
    <li><b>Customer Segment</b> – Segment of the customer (Consumer, Corporate, Home Office)</li>
    <li><b>Order Date</b> – Date when the order was placed</li>
</ul>

<ul>
